# Tree-sitter Kalcite

Tree-sitter grammar and highlighting queries for the Kalcite language. It is
consumed by the Zed extension and can also support other editor integrations.
The grammar covers declarations, `defer`, `if`/`else`, `while`, `break`, member calls,
binary expressions, and compound assignments used by the current toolchain.

```sh
npm install
npm run generate
npm test
```
